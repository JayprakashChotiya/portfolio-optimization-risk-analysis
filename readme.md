# Nifty 50 Portfolio Optimization & Risk Analysis

## 📌 Project Overview

This project applies **Modern Portfolio Theory (MPT)** to construct and evaluate optimized equity portfolios using a basket of **10 Nifty 50 stocks**. The analysis builds an efficient frontier, identifies the **Minimum Variance Portfolio** and **Maximum Sharpe Ratio (Tangency) Portfolio**, performs out-of-sample backtesting, and compares the strategies with the **Nifty 50 Index** and an **Equal-Weight Portfolio**.

## 🎯 Objective

* Construct an efficient frontier for selected Nifty 50 stocks.
* Identify the Minimum Variance and Maximum Sharpe portfolios.
* Evaluate portfolio returns and risk using quantitative performance metrics.
* Measure downside risk using **Value at Risk (VaR)** and **Conditional Value at Risk (CVaR)**.
* Backtest portfolio strategies out-of-sample.
* Compare optimized portfolios with Nifty 50 and equal-weight benchmarks.

## 📊 Methodology

### 1. Data Collection

Historical stock price data is obtained using `yfinance`. The project analyzes a basket of **10 Nifty 50 stocks** and calculates daily returns for portfolio construction and risk analysis.

### 2. Modern Portfolio Theory

Portfolio optimization is performed using:

**Minimum Variance Portfolio**

* Minimizes portfolio volatility.
* Focuses on reducing overall portfolio risk.

**Maximum Sharpe Ratio Portfolio**

* Maximizes the portfolio's Sharpe ratio.
* Seeks the best risk-adjusted return.

### 3. Efficient Frontier

The efficient frontier is generated by optimizing portfolio volatility for different target return levels. The Minimum Variance and Maximum Sharpe portfolios are then identified on the frontier.

### 4. Out-of-Sample Backtesting

The optimized portfolios are evaluated using out-of-sample data and compared with an Equal-Weight Portfolio and the Nifty 50 Index.

Performance is assessed using:

* Annualized Return
* Annualized Volatility
* Sharpe Ratio
* Maximum Drawdown

## 📈 Key Results

### Out-of-Sample Performance

| Portfolio        | Annualized Return | Volatility | Sharpe Ratio | Max Drawdown |
| ---------------- | ----------------: | ---------: | -----------: | -----------: |
| Minimum Variance |             8.20% |     12.03% |         0.10 |      -11.13% |
| Maximum Sharpe   |        **18.46%** |     13.73% |     **0.83** |       -9.19% |
| Equal Weight     |            14.25% |     12.47% |         0.58 |       -8.39% |
| Nifty 50         |            14.68% |     12.75% |         0.60 |      -10.93% |

The **Maximum Sharpe Portfolio** delivered the highest annualized return and Sharpe ratio among the portfolio strategies, indicating superior risk-adjusted performance in the out-of-sample period.

## ⚠️ Downside Risk Analysis

Portfolio downside risk was evaluated using **95% VaR and CVaR**.

| Portfolio        | 95% VaR | 95% CVaR |
| ---------------- | ------: | -------: |
| Minimum Variance |   1.10% |    1.58% |
| Maximum Sharpe   |   1.16% |    1.79% |
| Equal Weight     |   1.17% |    1.69% |

VaR estimates the potential daily loss at the 95% confidence level, while CVaR measures the expected loss beyond the VaR threshold.

## 📉 Benchmark Comparison

The optimized strategies were compared against the **Nifty 50 Index** and an Equal-Weight Portfolio to evaluate their relative performance.

The analysis considers both **return generation and risk-adjusted performance**, providing a broader assessment than evaluating returns alone.

## 🔍 Key Insights

* The **Maximum Sharpe Portfolio** achieved an 18.46% annualized out-of-sample return with a 0.83 Sharpe ratio.
* The Minimum Variance Portfolio reduced volatility to 12.03% but generated a lower 8.20% annualized return.
* The Maximum Sharpe Portfolio achieved a lower maximum drawdown (-9.19%) than the Nifty 50 (-10.93%).
* VaR and CVaR analysis provides additional insight into portfolio downside and tail-loss exposure.
* Portfolio optimization can be sensitive to return and covariance estimates, highlighting the importance of robust risk management.

## ⚠️ Limitations

The analysis has several limitations:

* Historical mean returns are subject to significant estimation error.
* Stock returns may exhibit non-normality, including fat tails and skewness.
* The covariance matrix is estimated statically and may change during market stress.
* Transaction costs and taxes are not incorporated into the backtest.
* Unconstrained Maximum Sharpe optimization can create concentration risk.
